# project-printtokens-with-faults
This is the project for my CSE 4308 course, Software Maintenance and Testing.
github: https://github.com/allim132/project-printtokens-with-faults.git

Group: Alex Nguyen, Hugo

In the src directory, you will find the source code.
In the test directiory, you will find the source code for the JUnit Tests.
In the target directory, these are files that are required for maven.
faults.txt is a file that is used to count how many faults were addressed per function.

How to run tests:
Run the command: "mvn test"
